# Khan Mebel — сайт

Сайт мебельной компании Khan Mebel (Астана): кухни и корпусная мебель на заказ, калькулятор стоимости, проекты, отзывы, цены, контакты.

Статический сайт без сборщиков и зависимостей: обычные HTML, CSS и JS. Подходит для GitHub Pages, Netlify, Vercel и любого хостинга.

```

│   ├── js/calculator.js      логика и цены калькулятора
```

## Как вносить правки

1. Тексты, отзывы, проекты, FAQ, цены в карточках, адрес и телефон — в `src/build.py`.
2. Цены калькулятора — в начале `assets/js/calculator.js` (объект `P`).
3. Стили — `assets/css/khan.css`.
4. Пересобрать страницы:

```bash
python3 src/build.py
```

Нужен только Python 3, без библиотек. После сборки закоммитьте изменённые HTML-файлы.

### Добавить проект в галерею

1. Положите фото в `assets/media/` в двух размерах: `имя.jpg` (до 1600 px) и `имя-s.jpg` (до 720 px).
2. Добавьте строку в список `PROJECTS` в `src/build.py`: имя файла, категория (`kitchen`, `living`, `hall`, `kids`, `bedroom`, `bath`), размер плитки (`big`, `wide`, `tall` или пусто) и подпись.
3. Запустите `python3 src/build.py`.

## Публикация на GitHub Pages

1. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Через минуту сайт будет на `https://khanmebel.vercel.app/`.

### Свой домен

1. Создайте в корне файл `CNAME` с доменом, например `khanmebel.kz`.
2. У регистратора домена добавьте DNS-записи для GitHub Pages (A-записи на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 или CNAME на `a3244440.github.io`).
3. В `src/build.py` поменяйте `DOMAIN` на `https://khanmebel.kz` и пересоберите — обновятся canonical, sitemap и разметка.
4. Добавьте сайт в Яндекс Вебмастер и Google Search Console и отправьте `sitemap.xml`.

## SEO и GEO

- Уникальные `title`, `description`, `canonical`, Open Graph и гео-теги на каждой странице.
- Разметка schema.org: `FurnitureStore` (адрес, координаты, часы, рейтинг 5.0 по 38 оценкам), `FAQPage`, `Service` с ценами, `BreadcrumbList`.
- `llms.txt` — краткая справка о компании для ИИ-ассистентов (ChatGPT, Perplexity, Яндекс Нейро).
- Семантическое ядро — в проекте KhanMebel на claude.ai (`semantic-core-khan-mebel.md`).

## Что подтвердить у клиента

- Реальные цены (сейчас стоят рыночные ориентиры по Астане).
- График работы (в разметке: ежедневно 10:00–20:00).
- Бесплатный ли замер, есть ли рассрочка и гарантия — это сильные преимущества для сайта.
